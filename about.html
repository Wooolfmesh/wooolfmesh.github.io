About

Wooolfmesh is built by Dzmitryi Kharlanau as a local-first system for making real work easier to execute, review and reuse.

DK

Dzmitryi Kharlanau

Dzmitryi is an SAP consultant and builder focused on local-first productivity systems, agentic work memory and practical execution loops.

Wooolfmesh grew from the need to manage real work: tasks, decisions, focus, reviews and lessons without putting the whole system into a SaaS black box.

The product direction is deliberately grounded: private local memory first, optional AI assistance second, and reusable execution context as the long-term advantage.
