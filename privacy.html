Privacy

Wooolfmesh is built from the assumption that private work memory should stay inspectable, portable and under user control.

User-owned Markdown vault

Tasks, memory, reviews and related work artifacts are designed to live in a local Markdown vault, not in a remote SaaS database.

SQLite is runtime support

SQLite supports reminders, events, metadata, caches and indexing. It is not the main ownership layer for user knowledge.

Optional AI providers

Local AI can help with extraction and reflection, but normal operation should not require hosted models or any AI service.

Preview-first changes

Capture and AI-assisted flows should show proposed entities before saving. No silent mutation is the operating principle.

External integrations are opt-in

Calendar, commitment or external sync directions should be explicit, scoped and reversible, not hidden background behavior.

No private vault data on this site

The public website must not publish private logs, sensitive screenshots, real vault contents, tokens or internal personal backlog data.

Control is the product boundary.

The core promise is not that a model will run your work. The core promise is that your work history becomes better organized, easier to review and more reusable without leaving your machine by default.

  • Open, human-readable storage where practical.
  • Local runtime support before cloud dependency.
  • Clear user action before private data leaves the machine.
