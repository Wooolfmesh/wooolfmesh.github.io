Why it exists

Real work is not just a task list. It is a chain of decisions, interruptions, focus attempts, reviews and lessons that should become easier to reuse over time.

What it connects

Tasks, capture, focus sessions, reviews, cognitive bites, projects, signals, analytics and local knowledge in one execution loop.

Built for real work, not AI theatre

AI is optional. The core is a local-first productivity loop that remains useful when no model is running.

Current status

The product is evolving. The public site documents the direction, install status, privacy model and roadmap honestly.

Local-first by design.

Markdown is the user-owned memory layer. SQLite supports runtime behavior. External integrations and AI providers remain optional.
