Support

Use GitHub issues and safe diagnostics. Review every file before sharing it publicly.

Where to get help

Open a GitHub issue at github.com/dkharlanau/work-os-local/issues.

Diagnostics

Export a diagnostics bundle from Settings when available. It should not contain private task content, passwords or API keys, but review it before attaching it publicly.

Common checks

  • Backend/frontend ports are free.
  • The configured vault path ends with _WorkOS.
  • Ollama or hosted AI providers are optional.
  • Store package instructions do not apply until a real package exists.
