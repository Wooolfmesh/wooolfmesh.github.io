Product

Wooolfmesh is a private local work system for keeping execution context alive: what to do next, why it matters, what happened, and what should be reused.

Getting startedPrivacy model

Today command center

Today is the operating layer: a daily view that pulls together priorities, readiness, focus context, reminders and review actions so the next move is explicit.

Tasks with next action and definition of done

Tasks are written for execution, not inventory. Each item can carry a next action, completion criteria, priority, project links and review history.

Capture and inbox

Capture is preview-first. Wooolfmesh helps extract tasks, links, memory and lessons from raw input, but nothing should be silently saved without the user choosing it.

Focus sessions

Focus sessions keep a task, goal, context and outcome together. The aim is to reduce restart cost when work is interrupted or resumed later.

Reviews

Daily, weekly, project and experience reviews turn finished work and friction into follow-up actions, patterns and reusable insight.

Cognitive bites / reusable lessons

Cognitive bites preserve compact lessons: decisions, heuristics, mistakes, prompts and operating rules that should help future work go faster.

Project health

Project views connect tasks, blockers, momentum and review signals so stale work and unclear commitments are visible before they become noise.

Signals and analytics

Lightweight analytics expose patterns in focus, completion, review debt and workload without turning private work into a cloud dashboard.

Optional AI providers

Local AI can assist with extraction, summaries and reflection. The product direction keeps AI optional and degraded behavior usable when no model is available.

Local knowledge / Markdown vault

The Markdown vault remains the durable ownership layer. Wooolfmesh reads and writes structured local files designed to stay inspectable outside the app.
