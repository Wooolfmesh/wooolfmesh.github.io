Install

Wooolfmesh is evolving. A public installer may not be ready yet, and the current setup can still be developer-oriented.

View source repositoryFollow roadmap

Current status

The app/source repository is available for inspection and development. Setup may require Node.js, Python and local configuration, so it is not yet positioned as a one-click consumer install.

Planned install path

The direction is a simple local install with Windows/macOS support, safer updates, clear backup expectations and a protected vault setup flow.

Requirements

Developer-oriented setup can involve a local web frontend, FastAPI backend, Python 3.11+, Node.js and an Obsidian-compatible Markdown vault. Ollama is optional.

Known limitations

Packaging, onboarding, demo assets, sanitized screenshots and public templates are still being clarified as part of productization.
