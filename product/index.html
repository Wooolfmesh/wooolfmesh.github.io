Wooolfmesh is a local execution workspace that remembers your work between sessions.

Request beta accessSee how data stays local

Product thesis

Most work tools remember objects. Wooolfmesh remembers continuity: what happened, why it mattered, which sources were used, and what should happen next.

Who it is for

It is for builders, consultants, researchers, and independent knowledge workers who already treat their notes as valuable infrastructure and want a resumable execution workspace over that knowledge.

Who it is not for

It is not a team project-management SaaS, not a hosted collaboration workspace, not a cloud database product, and not a generic AI chatbot interface.

How AI is used safely

Hermes and DIAL can propose capture candidates, task shapes, summaries, review ideas, and reflection prompts. Generated output is suggestion data. Durable writes require explicit approval through normal create or apply flows.

Value over time

The value compounds when yesterday's focus outcomes, review lessons, project signals, and cognitive bites reappear during today's planning and execution.

Current state

Implemented, partial, and roadmap

Status is grounded in the current WorkOS Local product docs and backlog.

Implemented

Implemented now

  • Work Thread with recorded outcome, decisions, sources, next move, and one primary action; supporting tools open on demand.
  • Markdown-backed tasks with planning fields: next action, definition of done, effort, energy, work mode, dates, reminders, links, and notes.
  • Preview-first capture for task, memory, and cognitive bite candidates.
  • Focus sessions with task context, interruptions, outcome, next action, and local analytics.
  • Cognitive bites, memory, quick links, reusable prompts, routines, signals, analytics, local notifications, weekly outcomes, and task shaping.
  • Knowledge search with scope controls, citations, result grouping, and read-only vault boundaries.
Partial

Partial or still being connected

  • Review, project, agent, and import suggestions exist, but the single daily follow-through rail is still being consolidated.
  • Project health exists, but the richer project workbench for movement, milestones, decisions, and recovery actions remains in progress.
  • Capture can save explicit entities, but capture queue discipline and multi-candidate processing need deeper product work.
  • Microsoft account connection and one-shot imports exist behind local control, but background polling sync is not implemented.
  • Package/store readiness, final installer validation, and public distribution hardening remain incomplete.
Roadmap

Roadmap

  • Calendar-aware capacity planning with richer external calendar context.
  • Microsoft To Do, Outlook Calendar, and Outlook Mail commitment sync beyond manual proposal import.
  • Operating manual rules surfaced at task shaping, Work recommendation, and focus start.
  • Custom Markdown-authored routines, local ritual automation, and store/package readiness.
