DefinitionA daily operating layer for priorities, readiness, reminders, focus context and review actions.

User problem

Daily work becomes scattered across task lists, notes, calendar pressure and unfinished review follow-ups.

What Wooolfmesh does

Wooolfmesh brings the next useful work, readiness signals and execution context into one local daily view.

Why it matters

The point is to reduce decision drag before work starts and make the next action explicit.

How it fits the core loop

Clarify → Plan → Focus → Review
