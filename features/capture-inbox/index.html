User problem

Important fragments arrive faster than they can be organized, then disappear into unreviewed notes.

What Wooolfmesh does

Wooolfmesh keeps capture explicit and preview-first so extracted entities can be reviewed before saving.

Why it matters

Fast capture is useful only when it does not silently mutate private work memory.
